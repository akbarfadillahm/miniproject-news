# 📰 Portal Berita Statis - 18 Mei 2026

Proyek ini adalah portal berita sederhana yang dibangun menggunakan **HTML5** dan **External CSS**. Fokus utama dari proyek ini adalah mengimplementasikan pemisahan antara struktur konten dan desain visual, serta mendalami penggunaan berbagai jenis selektor CSS sesuai standar pengembangan web modern.

---

## 🚀 Fitur & Materi Latihan
Proyek ini mencakup beberapa materi inti dari tutorial **Kelas Terbuka (Episode CSS - 06)**, antara lain:
- **Pemisahan File:** Menggunakan file eksternal `style.css` yang dihubungkan melalui tag `<link>`.
- **CSS Selectors:** Implementasi *Universal Selector* (`*`), *Class Selector* (`.artikel`), *ID Selector* (`#utama`), serta penggunaan *Span* untuk detail teks.
- **Layouting Dasar:** Pengaturan *box-sizing*, *margin*, *padding*, dan *box-shadow* untuk tampilan kartu artikel yang bersih.
- **Konten Real-Time:** Menampilkan ringkasan berita terkini per tanggal 18 Mei 2026.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5:** Untuk struktur semantik artikel.
- **CSS3:** Untuk styling eksternal dan manajemen tata letak.
